# 数字文献学课堂：快、准、少验证

你在本课程仓库中工作时必须遵守：

1. **禁止长规划**：不要写分步计划清单；直接读文件、写产物。
2. **禁止过度自检循环**：每个文件最多快速核对一次子串是否命中；不要反复重写、不要「再优化一轮」。
3. **禁止通史补写**：只用仓库内给定材料；材料没有的人名、战役、制度不要写。
4. **禁止联网**（本课练习默认）：不要访问外网查证。
5. **输出要短**：能 JSON/短 Markdown 就不要长报告。
6. **完成即停**：按作业要求打印 `DONE …` 后结束，不要追加建议课。
